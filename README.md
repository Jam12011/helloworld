## 📄 Source Code

```python
print("=" * 40)
print("🦖  ASCII T-REX  🦖".center(40))
print("=" * 40)

trex = """
                     __
                    / _)
             _.----/ /
            /         /
         __/ (  | (  |
        /__.-'|_|--|_|

           T - R E X
"""

print(trex)

print("=" * 40)
print("Rawrrr! 🦖".center(40))
print("=" * 40)
```
